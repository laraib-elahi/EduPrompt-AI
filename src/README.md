# Src Folder

This folder contains all source code for **EduPrompt AI**.

## Folder Structure
/src
  /backend     - FastAPI/Node.js APIs, LLM Gateway, Sandbox
  /frontend    - React + Tailwind CSS Web App
  /models      - Prompts, Evaluation Logic
  /utils       - Helper functions

## Technology Stack
- **Frontend**: React, Tailwind CSS
- **Backend**: FastAPI / Node.js Express
- **Database**: PostgreSQL + MongoDB
- **Sandbox**: Docker-based Code Execution
- **LLM**: OpenAI GPT / Google Gemini

## How to Run
Setup instructions will be added once development starts.

## Modules
1. **LLM Gateway**: Handles prompts to LLM
2. **Code Evaluation Sandbox**: Runs and tests student code
3. **Guidance Engine**: Gives feedback on prompts
4. **Auto-Marking**: Grades assignments
5. **Quiz Module**: Generates quizzes
